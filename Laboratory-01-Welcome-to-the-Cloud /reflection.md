# Reflection: 

KillerCoda provided a realistic entry point into Linux infrastructure management. Setting up my custom account (`jfalintag`), managing sudo rights, and configuring the Bash shell highlighted how fundamental access control and privilege management are to cloud security. Gathering system specs using utilities like `uname`, `lscpu`, `free`, and `df` demonstrated how system administrators evaluate resource availability before deploying workloads. Operating entirely within the terminal emphasized the importance of precision with file paths, system commands, and directory layouts. Translating these technical steps into structured Markdown files and organizing them within a public GitHub repository reinforced best practices for technical documentation and source control—two indispensable habits for any cloud engineer. This activity established a solid foundation in Linux fundamentals and version control. I look forward to expanding these skills into containerized applications, automated deployments, and advanced cloud architectures in upcoming CCM101 labs.
