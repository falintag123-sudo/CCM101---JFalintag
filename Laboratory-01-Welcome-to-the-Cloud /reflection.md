
# Reflection: 

Navigating a cloud-based Linux environment through KillerCoda provided vital hands-on experience with real-world server administration. Managing browser session timeouts taught an essential cloud lesson: infrastructure is ephemeral, making version control, prompt documentation, and GitHub backups critical for preserving work.

Key technical accomplishments included creating custom user accounts (`jfalintag`), granting `sudo` administrative access, and configuring interactive login shells. I acquired practical skills using essential CLI diagnostics (`cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`) to audit operating system builds, kernel versions, CPU architecture, RAM, and available disk space. Additionally, I built structured directory trees and authored standardized technical documentation.

In enterprise IT, cloud engineers rely almost exclusively on command-line interfaces. Mastering Linux navigation, system auditing, and clear Markdown documentation forms the bedrock for provisioning remote servers, troubleshooting automated deployments, and collaborating across engineering teams.
