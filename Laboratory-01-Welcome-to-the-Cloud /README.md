# Laboratory Activity 01: Welcome to the Cloud

## Mission Overview
This mission serves as the onboarding challenge for a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies. It focuses on navigating Linux environments, system auditing, file management, and GitHub version control.

## Objectives
* Access a cloud-based Linux environment using KillerCoda.
* Audit and record essential system information.
* Manage directory structures and files via the Linux terminal.
* Establish a version-controlled Cloud Computing Portfolio on GitHub.

## Activities Performed
* Provisioned a custom user account (`jfalintag`) with `sudo` privileges and assigned the default Bash shell.
* Collected system specs using standard Linux diagnostic tools.
* Created a structured workspace directory (`CloudComputing/Notes`).
* Authored system reports and personal profile files using Markdown.

## Linux Commands Used
* `sudo adduser` / `usermod` / `chsh`: User creation and permission configuration.
* `cat /etc/os-release` / `uname -r`: System and kernel verification.
* `lscpu` / `free -h` / `df -h`: Resource auditing (CPU, RAM, Storage).
* `mkdir -p` / `nano` / `mv`: Directory generation and file editing.

## Skills Learned
* Basic Linux System Administration
* Command-Line Interface (CLI) Fluency
* Technical Writing & Markdown Documentation
* Git & GitHub Portfolio Management
