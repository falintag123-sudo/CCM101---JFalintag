# Client Recommendations & Decision Matrix

## Client Recommendations

### Client A – Startup Company
* **Recommended Platform:** AWS (Amazon Web Services)
* **Justification:** AWS offers the AWS Activate program tailored for startups, granting infrastructure credits alongside immediate access to scalable tools. Their rapid scaling infrastructure will easily handle volatile growth while keeping initial overhead minimal through pay-as-you-go pricing models.
* **Services to Use:** AWS Amplify, Amazon EC2, Amazon DynamoDB.

### Client B – University
* **Recommended Platform:** Microsoft Azure
* **Justification:** The university relies heavily on Active Directory, Windows Server, and Microsoft 365, making Azure the most cost-effective and seamless path. Azure Active Directory (Entra ID) syncs directly with local users while the Azure Hybrid Benefit reduces licensing expenses significantly.
* **Services to Use:** Azure Active Directory (Entra ID), Azure Virtual Machines, Azure SQL Database.

### Client C – AI Research Company
* **Recommended Platform:** Google Cloud Platform (GCP)
* **Justification:** GCP offers industry-leading capabilities for high-performance computing, specialized Tensor Processing Units (TPUs), and advanced AI frameworks through Vertex AI. GCP simplifies training complex machine learning models faster and with lower latencies.
* **Services to Use:** Google Vertex AI, Cloud GPUs/TPUs, Compute Engine.

### Client D – Global E-Commerce Company
* **Recommended Platform:** AWS (Amazon Web Services)
* **Justification:** AWS provides unrivaled multi-region resiliency and global distribution features required for mission-critical e-commerce platforms. Their battle-tested auto-scaling features and global CDN handle massive unpredictable traffic spikes effortlessly.
* **Services to Use:** Amazon CloudFront, AWS Auto Scaling, Amazon Aurora.
