Out of all three platforms, Google Cloud Platform (GCP) impressed me the most because the dashboard is clean, the built-in terminal is easy to use, and it is really good at handling containers with Kubernetes. 

While exploring AWS, Azure, and GCP, I noticed that they actually do a lot of the same basic things. They all give you virtual computers to run programs, storage space to save files, virtual networks to connect everything, and security tools to manage who gets access. 

I learned that picking a cloud platform depends heavily on what a business actually needs. You shouldn't just pick the most popular platform; you have to think about budget, what the team already knows, and what tools the project needs. For example, a company that already uses a lot of Microsoft software will save more time and money using Azure.

Acting as a Cloud Solutions Consultant helped me think about real-world problems. I learned that my main job isn't just about picking cool technology, but finding the right balance between cost, performance, and how easy the system is to manage.

Lastly, writing all of this down in my GitHub portfolio helped me practice organizing my work and writing clear documentation. Keeping my files neat and using tables makes it much easier to explain my technical choices, which will be really useful for my future projects.
